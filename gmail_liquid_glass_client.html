How to get a Google Client ID:

  1. Go to Google Cloud Console.
  2. Create a project and enable the Gmail API.
  3. Under OAuth consent screen, set user type to External and add your email as a test user.
  4. Under Credentials → Create OAuth 2.0 Client ID (Web Application).
  5. Add your GitHub Pages or local URL to Authorized JavaScript origins.
